# pnet — Android

Каталог для Android-клиентов сети pnet. Две ветки:

- [fork/](fork/) — форк официального Android-приложения EasyTier с поддержкой
  произвольного DNS-сервера (поле `dns` в конфиге сети). Это патч, который
  накладывается поверх тега `v2.4.5` — той же версии ядра, что использует pnet.
- [app/](app/) — собственное нативное Android-приложение pnet (Go).

## Почему форк EasyTier первым

pnet уже использует `easytier-core` v2.4.5 как ядро виртуальной сети, а его DNS
(по умолчанию `10.126.0.1`) поднимается внутри сети как Magic DNS. Официальное
Android-приложение EasyTier умеет подключаться к той же сети, но **не умеет
задавать DNS**: Android-сервис VPN всегда использует `114.114.114.114`
(`tauri-plugin-vpnservice/android/src/main/java/TauriVpnService.kt:75`), и в UI
нет поля для своего DNS. Без патча адреса из сети pnet по именам не резолвятся.

Форк минимальный: добавляется поле `dns` в конфиг сети, оно передаётся в
`VpnService.addDnsServer()`, а DNS-сервер дополнительно получает маршрут `/32`
через туннель (иначе Android не сможет до него достучаться — в VPN попадают
только явные маршруты).
